# C · CORE-CLUSTER · RESPO

Der Ordner **C/** ist ein zentraler Cluster-Raum innerhalb des iki1uc-Systems.
Er dient als Sammelpunkt für TMP-Module, RESPO-Scans und Cluster-Analysen.

C ist vollständig unabhängig und kann folgende Module laden:

- TMP-Cluster
- RESPO-Argument-Scan
- Operator-Module
- Schach-Module
- Morph-Module
- Nord/Ost/Süd/West-Räume
- XARG-Module

## Funktionen

### 1. Cluster-Raum
`C.room` definiert den Kernraum des Clusters.

### 2. TMP-Scan
Alle `.tmp` Dateien werden eingelesen und als Panels dargestellt.

### 3. ID-System
`id.html` zeigt Cluster-ID, Status und Struktur.

### 4. Index-System
`index.html` lädt alle Dateien und zeigt sie als Panels.
