# C · OPERATOR-CLUSTER · MIND-ID · CR-READY

C ist der Operator-Knoten des Systems.  
Er verbindet SCAN, ARG, TMP, SCHACH, OCTA, MORPH, ERROR, FIT, SCORE und die Richtungsachsen NORD/OST/SÜD/WEST.

C arbeitet unter dem Master CUBE-MIND und führt die Operatoren aus, die in den *.tmp Dateien definiert sind.

---

## 🧠 C-ID

Die Identität von C wird in `C.room` definiert:

- **ID:** C  
- **ROLE:** Operator-Cluster  
- **SIGNATURE:** gamma  
- **MASTER:** CUBE-MIND  
- **STATUS:** active  

Diese ID wird in `id.html` angezeigt.

---

## 🔱 Operatoren (*.tmp)

C besitzt eine große Anzahl Operatoren, die jeweils eine Funktion tragen:

- **SCAN.tmp** — Scan-Achse  
- **ARG.tmp** — Argument-Achse  
- **TMP.tmp** — temporäre Achse  
- **SCHACH.tmp** — Schach-Operator  
- **schachac.tmp** — Schach-Achsen  
- **bauer.tmp / dame.tmp / pferd.tmp / tetriz.tmp / skat.tmp** — Figuren-Operatoren  
- **OCTA.tmp** — Oktagon-Achse  
- **MORPH.tmp** — Morphing-Achse  
- **ERROR.tmp** — Fehler-Achse  
- **FIT.tmp** — Fit/Match-Achse  
- **SCORE.tmp** — Bewertungs-Achse  
- **help.tmp / edit.tmp / operator.tmp** — Hilfs-Operatoren  

Richtungsachsen:

- **nord.tmp**  
- **ost.tmp**  
- **sued.tmp**  
- **west.tmp**  
- **up.tmp**  
- **in.tmp**  
- **x.tmp / xarg.tmp / z.tmp**  

Temporäre Achsen:

- **tmp.a / tmp.e / tmp.g / tmp.h / tmp.o / tmp.s / tmp.po.raer.tmp**
